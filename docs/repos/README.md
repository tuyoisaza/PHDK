# PHDK downstream repository status registry

This directory contains the current PHDK adoption and stack-security status snapshots published by eligible repositories under `tuyoisaza/*`.

Canonical contract: [PHDK_REPOSITORY_STATUS.md](../../PHDK_REPOSITORY_STATUS.md).

Each repository writes only:

```text
docs/repos/<repository-name>/status.md
```

These records are foreground reporting artifacts. They are not telemetry, background monitoring, or proof that every repository has been reviewed. Absence of a file means no eligible published status is currently available.
